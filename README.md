# my-lotus.app

Website for the MyLotus iOS app: landing page + Privacy, Terms and Support pages (EN/FR).
Static site, no build step. Deployed by Netlify from the `main` branch (publish directory: `/`).

- `index.html`: landing page. App Store link: `APP_STORE_URL` near the top of the script.
- `privacy/`, `terms/`, `support/` (+ `.html` copies, kept for links already used in the app).
- `assets/`: styles, logo, QR code library.
